# Лабораторна робота: k-NN Класифікатор (Python)

Реалізація алгоритму k-найближчих сусідів (k-NN) для задачі класифікації без використання бібліотек машинного навчання для самої моделі.

## Структура проєкту

* `IrisData_full.csv` — вхідний набір даних з параметрами квіток ірису (Iris Dataset).
* `data_loader.py` — завантаження даних, перетворення текстових міток класів на числові значення та нормалізація ознак.
* `knn_classifier.py` — реалізація алгоритму класифікації на основі евклідової відстані, мажоритарного голосування та функція пошуку найкращого параметра $K$.
* `main.py` —  головний скрипт для запуску, пошуку найкращого K, оцінки точності та візуалізації.
